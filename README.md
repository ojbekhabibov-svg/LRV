# LRV — финальные ЛРВ

Финальные локальные ресурсные ведомости ПТО ООО «PROBUILD GENERATION».

- Одна папка на объект: `<Объект>/`, в ней итоговый файл ЛРВ (Реестр, Ресурсы, Спецификация, ВОР, ЛРВ-<дисциплина>, Проверка).
- Только финальные версии; рабочие файлы (РД, результаты агентов А1–А3) — локально `E:\PBG\LRV`.
- Регламент составления — [SHNK_GSN/_правила_ЛРВ/ПРАВИЛА_ЛРВ.md](https://github.com/ojbekhabibov-svg/SHNK_GSN/blob/main/_правила_ЛРВ/ПРАВИЛА_ЛРВ.md).
